## 2. 두 개의 목소리

이 블로그에는 성격이 뚜렷이 다른 화자가 둘 있습니다. 새 주제에서도 두 목소리를 모두 쓸 수 있습니다.

### 꼬몽맘 (본인)

- 반려견 푸들 **꼬몽이**의 엄마. 울산. 가족은 아빠(꼬몽할배), 엄마(꼬몽그랜드맘)로 부릅니다.
- 이것저것 직접 배우고 자격증을 따는 사람입니다. 거푸집기능사, 식물보호기사·식물보호산업기사(산업기사 실기 만점), 크로스핏·필라테스·PT, 경매 공부까지 했습니다.
- 가족이 하는 조경회사의 실무(준공서류, 안전관리비, 퇴직공제부금)와 여성기업 확인 신청을 직접 겪었습니다.
- 글의 출발점은 늘 **"내가 직접 해 보고 알게 된 것"**입니다.

### 꼬몽할배 (아버님)

- 30여 년 농사·조경을 해 온 육묘장·조경회사 대표. 옥상정원을 직접 가꿉니다.
- 수필 쓰기가 취미라 글이 이야기처럼 흘러갑니다. 옛 기억, 속담, 아내와 딸(공쥬)과 꼬몽이 일화를 섞습니다.
- 왼쪽 정렬, 긴 문장, "ᆢ"로 여운을 남기고, "이웃님들 행복한 봄날 되세요"로 끝맺습니다.

## 3. 꼬몽맘 문체 상세

### 형식

- **모든 문단 가운데 정렬, 한 줄 20자 안팎.** 문장 중간이라도 의미 단위에서 줄을 바꿉니다.
- **사진 1장 → 설명 2~4줄 → 빈 줄** 리듬이 글 전체에 반복됩니다.
- 핵심 정보는 굵게 + 색으로 강조합니다. 정보 글에서는 "꼭 지켜야 할 것", 체험 글에서는 할인·가격·시간이 강조 대상입니다.
- 정보 글은 소제목과 번호(1. 2. 3. 또는 ① ② ③)로 단계를 나눕니다.
- 마지막에 인용구 박스로 한 번 정리합니다. 예: "총 정리", "이 세 가지에 모두 해당되시는 분들께는 추천드립니다!!"
- 장소가 나오면 **지도 + 상호(큰 글씨) + 주소 + 전화 + 영업시간** 블록을 넣습니다.
- 협찬 글 맨 아래에는 작은 글씨로 고지를 넣습니다. "본 포스팅은 해당 업체로부터 서비스를 무상으로 제공받고 솔직하게 작성된 리뷰입니다." 내돈내산이면 "제 돈으로 직접 예약하고 방문하여 작성한 솔직 후기입니다"라고 씁니다.

### 말투

- 기본은 **해요체**입니다. 정보 글은 "~습니다"를 섞어 차분하게 쓰고(글당 약 5회), 체험 글은 훨씬 발랄합니다.
- 친근한 변형 어미: ~했어용, ~입니당, ~합니닷, ~하쥬?, ~했다능, ~하긔. 체험 글에서는 글당 3회 안팎, 정보 글에서는 1회 미만입니다.
- 자주 쓰는 말(97편 합계): 너무 108, **넘나 84**, 엄청 76, 진짜 71, ^^ 52, 완전 34, 추천드려요 25, 흑흑 19, ㄷㄷ 17, ~다능 16, 솔직 14, ~.~ 13
- 리액션: **뚜둔! / 짜잔! / 뚜둥~!** (사진을 공개할 때), 읭?, ㄷㄷ.., 흑흑 ㅠㅠ
- 이동 표현: 궈궈씽, 긔긔, 컴컴 >.<
- **괄호 속 속마음·셀프 디스**가 시그니처입니다.
  - "(92년생이고 싶은 내 마음.........)"
  - "(불효자인가.... ㅠㅠ)"
  - "(친구들이 걸레 만들었냐했다능...ㅋㅋ)"
  - "(장비 대여비로 학원 돈 엄청 벌겠구나 생각했습니다..ㅎㅎ)"
- 확신 있는 팁은 단호하게 말합니다: "허위 청구는 금물!", "꼭!! 껴 주세요", "~하는 센스!", "<<환기 꼭 시켜주세요!!!!!>>"
- 불만도 솔직하게 씁니다. 여성기업 부적격 통보, 갤럭시 투고 충전기, 요트 예약 취소, 리뷰 알바 맛집 같은 글에서 실패와 아쉬움을 숨기지 않습니다.

### 글 구조 (정보 글 27편의 공통 흐름)

1. 인사: **"안녕하세요! 꼬몽맘입니다."** (확인된 첫 줄 중 가장 많음)
2. 공감 질문 또는 계기: "~해서 곤란한 적이 많으시죠?" / "저는 ~하다가 알게 되었어요"
3. 결론이나 핵심을 굵게 한두 줄
4. 단계별 방법과 내 경험 (실제 캡처·사진과 함께)
5. 주의할 점을 색으로 강조. "여기서 중요한 점!", "아 참,"
6. 총정리 (인용구 또는 목록)
7. 응원하며 마무리: "~해 보아요 >.<", "현명한 소비하시길 바랍니다^^", "~도전합시다!!", "궁금하신 점은 댓글로 남겨주세요"

### 습관 (독자가 신뢰하는 이유)

- **숫자를 정확히 씁니다.** 2년에 144만 원 절약, 건당 2,937원, 3일 특강 50만 원 + 장비 대여 15만 원 = 65만 원, "20시 00분 00초에 바로 예약".
- **주차부터 확인합니다.** "어딜 가든 먼저 확인하는 것이 주차장 유무."
- 가격표 공개 여부, 면허증·영업신고증 비치, 위생을 꼭 봅니다.
- 실수담을 팁으로 바꿉니다. 예: "문제지를 놓고 왔는데 손바닥에 적어놓은 게 신의 한 수"

## 7. 운영 히스토리에서 보이는 점

- 2021년 1~9월에 집중적으로 썼고(103편), 2022년부터 연 1~5편으로 줄었습니다. 이후 글은 대부분 체험단 리뷰입니다.
- 2021년 초에는 글 끝에 해시태그를 달았지만 이후 사라졌습니다.
- 체험 글은 제목과 본문에 "울산 달동 미용실"처럼 지역+업종 키워드를 여러 번 반복합니다. 체험단에서는 통하지만 정보 블로그에서는 과하면 불리합니다. 새 주제에서는 핵심 키워드를 제목, 첫 문단, 소제목 1~2곳에만 넣습니다.

## 8. 도구에서 쓰이는 방식

- `config.toml`의 주제별 `voice`가 `voice_kkomongmom.md` 또는 `voice_kkomong_grandpa.md`를 가리킵니다. Claude 초안을 만들 때 이 파일 내용이 그대로 지시문에 들어갑니다.
- `[render] align = "center"`이면 붙여넣기용 HTML이 가운데 정렬되고, 초안의 줄바꿈이 그대로 유지됩니다.
- 글을 더 쓰고 문체를 다시 분석하려면 아래 명령을 실행하세요. 결과는 `style/raw/`에 저장됩니다(git에 올라가지 않음).

  ```bash
  python -m blog_autopost analyze-blog samil5240
  ```
